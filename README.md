# Portfolio

A modern, interactive portfolio website built with React and modern web technologies.

## 🚀 Live Demo
[View Live Portfolio](https://aranzanzo-aethan-portfolio.vercel.app/)

## 📋 About
This is a personal portfolio website showcasing projects, skills, and experience. It features a responsive design, smooth animations, and AI-powered features.

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/AethanAranzanzo/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Create a `.env` file for environment variables:
   ```bash
   VITE_GOOGLE_API_KEY=your_google_api_key_here
   ```

### Available Scripts

- **Development**:
  ```bash
  npm run dev          # Start Vite dev server
  npm run dev:api      # Start Express API server
  ```

- **Build**:
  ```bash
  npm run build        # Create production build
  npm run preview      # Preview production build
  ```

- **Linting**:
  ```bash
  npm run lint         # Run ESLint checks
  ```

## 📝 Development Workflow

1. Start the development server:
   ```bash
   npm run dev
   ```

2. In another terminal, start the API server (if needed):
   ```bash
   npm run dev:api
   ```

3. Open your browser and navigate to `http://localhost:5173`

4. Make changes to the source files in `src/` and see live updates

## 🏗️ Building for Production

```bash
npm run build
```

This creates an optimized production build in the `dist/` directory, ready to be deployed.

## 🌐 Deployment

This project is deployed on **Vercel**. The `vercel.json` configuration handles the deployment setup.

To deploy your own version:
1. Push to GitHub
2. Connect your repository to Vercel
3. Vercel will automatically build and deploy on each push
